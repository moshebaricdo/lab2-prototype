# Daily Check-In Planner

This project is a small Python script that turns a student's name into a short coding plan for the day.

## Try This

1. Run `main.py` and read the console output.
2. Change the items in `FOCUS_OPTIONS`.
3. Add a new custom encouragement in `ENCOURAGEMENTS`.
4. Keep the final output easy to read in the console.
