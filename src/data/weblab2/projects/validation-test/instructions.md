**Expected Behavior:** Clicking the Next button should show a new photo and caption on the page.

**1: Test it:** Run the code and click the button once. What happens (or doesn’t happen)?

**2: Check the basics:** Look for small mistakes that can break the connection between the button and the action.

- **Selector match:** Does the JavaScript selector match the HTML id or class exactly?
- **Element exists:** Is that element actually on the page?
- **Order:** Are elements selected before they’re used?
- **Event setup:** Is 'click' spelled right (not 'onclick')?
- **Handler:** Does the code actually change the page (text, image, etc.)?

> *Why isn't this button working? Here's the error or result: [insert error here]. Explain it in beginner terms and suggest what to check first.*
